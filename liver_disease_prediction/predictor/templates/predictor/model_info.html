Reproducing Model Evaluation
CLI Management Command

To re-verify and evaluate the model artifact against the local dataset using 5-fold cross-validation and stratified train/test partitioning, run the following Django command:

python manage.py evaluate_model --save

This command executes cross-validation in memory, recalculates accuracy, precision, recall, F1, and the confusion matrix, and updates data/evaluation_metrics.json without retraining or altering the saved pipeline artifact.

Important Scientific Limitation & Generalization Notice:

Evaluation metrics reported on the UCI Indian Liver Patient Dataset (ILPD) reflect performance on this specific retrospective cohort. These metrics do not establish clinical efficacy, diagnostic reliability, or generalization to external patient populations or other clinical environments. This software is designed strictly for research and educational purposes.
